상속세 계산기 PWA 패키지

구성
- index.html: 사용자 화면
- app.js: 입력·계산·브라우저 저장
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 오프라인 캐시
- icon-192.png / icon-512.png: 앱 아이콘

설치 전제
1. 이 폴더의 파일을 HTTPS를 지원하는 정적 웹호스팅에 업로드해야 합니다.
2. 웹 주소를 안드로이드 Chrome 또는 Samsung Internet에서 엽니다.
3. 브라우저 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

중요
- 현재 패키지는 PWA 설치용 초기 버전이며, 공개 URL에 배포된 상태가 아닙니다.
- 브라우저 저장소(localStorage)에 입력값을 저장합니다. 기기·브라우저별 저장이며 서버 동기화나 암호화 저장은 구현하지 않았습니다.
- 세법 계산은 교육·검토용 단순화 모델입니다. 법정 요건의 자동 판정이나 신고서 확정용으로 사용하면 안 됩니다.
- 실제 배포 전 HTTPS, 개인정보 처리방침, 접근통제, 백업, 법령 기준일별 테스트가 필요합니다.
